# Wood Design: Engineered Wood Products

Study site for ENGR-3017 Wood Design (Fanshawe), Test 2: engineered wood products.

**Open it:** https://ghostbadger.github.io/Wood-Design-Engineered-wood-products/

- Guided lessons with a 7-day plan to the test
- A5-style test sheets: a new house each time, every box marked, mistakes carried forward
- Drills, a 3D model of the A5 house, and the Site Super game
- Table notes to copy onto your printed TJ-4510 and TJ-9500
- Printables in `print/`: A5 blank sheet, A5 worked key, table notes and method card

Progress saves in each person's own browser. After the first visit the site also works without a connection.

Personal study notes, not a design tool. Always check your own copy of the Trus Joist guides and the code.
